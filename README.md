# DevToolbox

Suite local de ferramentas para acelerar tarefas comuns de desenvolvimento, acionadas principalmente por atalhos globais no Windows.

## Objetivo inicial

Permitir que o usuário transforme o conteúdo da área de transferência sem trocar de janela. Exemplo: após copiar um texto, pressionar `Ctrl+Alt+J` executa uma transformação configurada e coloca o resultado de volta no clipboard, pronto para colar.
